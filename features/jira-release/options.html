Фильтр по меткам

На странице релиза над списком Work items — чипы меток задач релиза с числом задач. Клик — показать задачи с меткой, Shift+клик — скрыть; несколько меток — «любая из выбранных» или «все выбранные». Там же — копирование видимых задач и ссылка на тот же отбор в поиске Jira. Метки берутся запросом к API Jira того же сайта под вашей сессией: в строках списка их нет.

Через запятую или пробел, без учёта регистра. У каждой задачи релиза должна быть хотя бы одна из них: чип «без обязательных меток» оставляет задачи, у которых нет ни одной. Обязательные метки в чипах выделены. Пусто — чипа нет.

Метки в списке

Все метки задачи по алфавиту — сразу после названия, без сокращения: если места мало, сокращается название. Обязательные метки выделены. Клик по метке работает как клик по её чипу.

MR в списке

Кнопка «Посмотреть MR» справа от статуса задачи — открывает MR из поля задачи в новой вкладке, а не задачу; несколько MR — кнопка на каждый с номером. Берутся в том же запросе, что и метки, плюс один запрос списка полей — найти поле по названию.

Название поля, как в задаче, без учёта регистра. Пусто — «Merge Request».
