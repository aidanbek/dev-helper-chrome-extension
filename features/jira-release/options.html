Фильтр по меткам

На странице релиза над списком Work items — чипы меток задач релиза с числом задач. Выбранные чипы оставляют в списке задачи хотя бы с одной из выбранных меток. Метки берутся запросом к API Jira того же сайта под вашей сессией: в строках списка их нет.

Через запятую или пробел, без учёта регистра. У каждой задачи релиза должна быть хотя бы одна из них: чип «без обязательных меток» оставляет задачи, у которых нет ни одной. Обязательные метки в чипах выделены. Пусто — чипа нет.

Метки в списке

Все метки задачи по алфавиту — сразу после названия, без сокращения: если места мало, сокращается название. Обязательные метки выделены.
